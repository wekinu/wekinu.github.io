과부하 주사위 개인정보 처리방침

gagadodo · kmymgd@gmail.com · 2026-10-12

요약

과부하 주사위은 인터넷 없이 기기 안에서만 동작하는 게임이야. 계정, 광고, 결제, 분석(통계) 도구가 없고, 게임이 개발자에게 자동으로 보내는 정보는 없어. 개인에게 이어질 수 있는 정보가 개발자에게 가는 경우는 사용자가 직접 의견 메일을 보낼 때뿐이야(아래 설명).

이 기기에 저장되는 정보

진행 중인 판, 설정(소리·배경 음악·음량·연출 세기·진동), 해금한 항목, 최고 기록과 최근 플레이 내역(최대 50판: 날짜, 모드, 시드, 결과, 점수, 사용한 조합과 능력)이 저장돼.

저장이 중간에 끊겨도 이전 상태를 지킬 수 있도록 앱 전용 저장 공간에 같은 내용의 복구용 사본이 함께 보관돼.

이 정보는 앱 전용 저장 공간에만 있고 다른 앱이 읽을 수 없어. Android 자동 백업(클라우드 백업)과 기기 간 데이터 이전에 포함하지 않도록 앱에 명시해 두었어. 그래서 기기를 바꾸면 이 기록은 옮겨지지 않고, 새 기기에서는 처음부터 시작해. 제조사가 제공하는 별도의 이전 도구는 제조사 방식에 따라 다를 수 있어.

삭제와 보관

설정 > 데이터 관리에서 진행·기록·설정을 한 번에 지울 수 있고, 복구용 사본도 함께 지워져.

앱을 제거하면 저장된 모든 정보가 사라져. 보관 기간은 사용자가 지울 때까지(또는 앱을 제거할 때까지)야.

사용자가 직접 누를 때만 일어나는 외부 동작

의견 보내기: 메일 앱의 작성 화면이 열려. 본문에는 앱 버전, Android 버전, 기기 모델이 미리 들어 있고 보내기 전에 직접 보고 고치거나 지울 수 있어. 진행 상황, 시드, 저장 파일, 기기 식별자, 로그는 자동으로 붙지 않아. 메일은 사용자가 메일 앱에서 보내기를 눌러야만 전송돼.

사용자가 메일을 보내면 보낸 사람의 메일 주소와 메일 내용(미리 들어 있던 앱·기기 정보 포함)이 개발자(kmymgd@gmail.com)에게 전달돼. 이 내용은 의견에 답하고 문제를 고치는 데에만 쓰고, 다른 곳에 제공하지 않아. 자동 삭제 기간은 따로 정해 두지 않았고, 삭제를 원하면 같은 주소로 요청해 줘. 메일 자체는 사용자가 쓰는 메일 서비스에도 남아.

공유하기: 사용자가 선택한 결과 문장 또는 설치 파일(APK)을 Android 공유 창으로 넘겨. 받는 앱과 사람은 사용자가 고르고, 선택한 앱이 그 내용을 어떻게 다루는지는 해당 앱의 정책을 따라.

평가하기: 이 게임이 Google Play에 등록되면 Play 상세 페이지를 열어. 등록 전에는 아무것도 열지 않고 안내만 보여 줘.

권한

진동 권한 하나만 사용해(설정에서 켠 경우의 짧은 진동). 인터넷, 저장소, 위치, 카메라, 마이크, 연락처 권한은 쓰지 않아.

아이와 제3자

게임이 자동으로 수집하는 정보가 없어서 연령에 따라 다르게 처리하는 정보도 없어. 사용자가 보낸 의견 메일의 내용은 의견 처리 외의 목적으로 쓰거나 제3자에게 제공하지 않아. 공유하기로 보낸 내용은 사용자가 고른 앱이 받아.
